# Giovanni Nadaja | Portfolio Full Stack

Portfolio personal full stack desarrollado con React + Vite en el frontend y un backend separado en PHP + MySQL, pensado para mostrar mi experiencia, proyectos y habilidades como desarrollador web.

## Sobre el proyecto

Este proyecto es mi portfolio personal y espacio profesional para presentar mi trabajo como desarrollador full stack. Lo construí para mostrar mi experiencia real, mis proyectos, casos de uso prácticos y la capacidad de integrar frontend y backend en soluciones completas.

## Tecnologías usadas

### Frontend
- React
- Vite
- React Router
- Context API
- JavaScript / JSX
- CSS personalizado

### Backend
- PHP
- MySQL
- APIs propias para autenticación y gestión de datos
- Integración con frontend para formularios y servicios dinámicos

## Funcionalidades

- Portfolio personal con experiencia profesional y proyectos reales
- Sección de habilidades técnicas y stack principal
- Visualización de repositorios de GitHub consumidos desde la API pública
- Demo de landing page comercial para presentar una propuesta de negocio
- Demo de e-commerce con catálogo, carrito y checkout simulado
- Sistema de registro e inicio de sesión conectado a backend PHP/MySQL
- Selector de idioma en Español, English y Português
- Formulario de contacto integrado con backend
- Contador de visitas en vivo mediante backend propio
- Diseño responsive y enfocado en una presentación profesional

## Cómo correrlo en local

1. Cloná el repositorio:
   ```bash
   git clone https://github.com/tu-usuario/tu-repositorio.git
   cd tu-repositorio
   ```

2. Instalá las dependencias:
   ```bash
   npm install
   ```

3. Ejecutá la aplicación en modo desarrollo:
   ```bash
   npm run dev
   ```

4. Abrí la app en tu navegador:
   ```bash
   http://localhost:5173
   ```

> El backend PHP/MySQL se encuentra separado y debe configurarse en su entorno correspondiente si querés probar funciones reales de login, registro o formularios conectados a base de datos.
